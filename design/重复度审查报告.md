# AIFusion 桌面端 · 与上游 cc-switch 的重复度审查

审查时间：2026-10-21 ｜ 对比基线：上游 `farion1231/cc-switch` **v4.0.15**（本项目 fork 的同版本号，逐文件同路径比对）
统计口径：非空行去掉首尾空白后做多重集交集，交到的行算「重复行」；重复度 = 重复行 ÷ 本项目总行数。
统计范围：`src/**`、`src-tauri/src/**`、`tests/**`、`public/**`、`index.html`、`package.json`、`tsconfig*`、`vite.config.ts`、`tailwind.config.*`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`、`scripts/**`（不含 node_modules / dist / target）。

## 一、结论：超标，而且远超 90% 红线

| 口径 | 文件 | 行数 | 重复行 | 重复度 | 完全相同文件 | 自有新文件 |
|---|---:|---:|---:|---:|---:|---:|
| **全项目** | 747 | 376,641 | 364,730 | **96.8%** ❌ | 577 | 26 |
| 前端 `src/` | 317 | 90,783 | 85,870 | **94.6%** ❌ | 264 | 16 |
| 可见 UI（components + App + tray-panel + css） | 174 | 50,268 | 46,534 | **92.6%** ❌ | 151 | 11 |
| 纯展示组件 `src/components/` | 166 | 47,201 | 45,089 | **95.5%** ❌ | 150 | 5 |
| Rust 后端 `src-tauri/src` | 297 | 257,192 | 251,379 | **97.7%** ❌ | 201 | 5 |
| 测试 `tests/` | 128 | 28,316 | 27,161 | 95.9% | 111 | 5 |
| i18n 文案 | 6 | 21,640 | 20,772 | 96.0% | 1 | 0 |

我们自己写的代码只有 **26 个文件 / 7,284 行，占全项目 1.9%**：托盘面板（`src/tray-panel/**`、`src-tauri/src/tray_panel.rs`）、平台连接卡与模型选择器（`PlatformConnectionPanel`、`PlatformModelDialog`）、首页总览（`HomeOverview`、`AppModelCard`）、平台登录/密钥/模型服务（`platform_login.rs`、`platform_key.rs`、`platform_model.rs`）和对应的 4 个测试。其余全部是上游原样：`src/components/ui/**` 23 个原子组件 100% 未改，`src/index.css` 设计 token 100% 未改，图标资源 100% 未改，`skills/mcp/sessions/usage/settings/apps/prompts` 等 114 个百行以上展示组件 95–100% 与上游一致（合计 41,908 行）。

## 二、关键发现：删功能降不了重复度，只有替换能降

因为每个功能域几乎都是 97–99% 重复，删掉一块代码会同时把分子和分母一起变小，比值几乎不动。模拟结果：

| 手段 | 结果 |
|---|---|
| 删掉上游本地路由/代理引擎（83,412 行） | 96.2% ❌ |
| 再删供应商表单与渠道（41,405 行） | 96.3% ❌ |
| 再删会话+用量+MCP+Skills+提示词（71,665 行） | 95.0% ❌ |
| **组合删除 8 个域共 64,646 行** | 96.3% ❌ |
| **自研可见 UI 层**（替换 46,534 行） | **84.5% ✅** |
| 再自研 i18n 文案（替换 20,772 行） | **79.0% ✅** |
| 再自研状态与 API 层（替换 16,224 行） | **74.7% ✅** |
| 删路由引擎+渠道表单，并自研 UI+i18n | **70.9% ✅** |
| 上式基础上再自研 Rust 服务层 60k 行 | **47.9% ✅** |

换算成一句话：**要低于 90%，最少要把约 2.6 万行上游代码换成我们自己的实现**（或者纯新增 28,615 行自有代码去摊薄，但那只是数字游戏，界面照旧）。单靠删除永远达不到。

## 四、建议路线（分三阶段，每阶段结束都重跑本审查）

阶段一「界面全新」：自研设计系统（token、字体、间距、圆角、图标集全部替换上游 `src/index.css` + `components/ui/**`），重做外壳（标题栏/侧栏/导航/页面骨架）与全部保留页面（首页总览、客户端详情、MCP、Skills、提示词、会话、用量、设置），i18n 文案按 AIFusion 术语重写。→ 预计 84.5% → 79%。
阶段二「砍掉上游不需要的能力」：本地路由/代理引擎、供应商表单与渠道、云同步（WebDAV/S3）、配置档切换、深链导入、OAuth/托管授权、流式自检、用量脚本。→ 代码规模显著收缩，重复度 70.9%。
阶段三「引擎自研」：把各客户端配置写入、模型投影、用量采集等 Rust 服务层按 AIFusion 的数据模型重写。→ 47.9%。
