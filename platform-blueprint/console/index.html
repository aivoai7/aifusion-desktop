控制台占位页

这里不是产品，只是让 docker compose up 在控制台写完之前也能起来并拿到证书。 真实的管理端要在本目录实现，至少要覆盖这几条路由：

  • 登录 / 桌面回环分发 GET /desktop/connect
  • 用量汇总（对账用，与网关同源同口径） GET /api/v1/admin/usage/summary
  • 钱包与流水 GET /api/v1/admin/wallet/ledger
  • 渠道与价目 GET /api/v1/admin/pricing
  • 请求策略（只按体积，不按条数） GET /api/v1/admin/settings/request_checks
